# Hướng dẫn Cài đặt JAVIS Driver Premium — MVP V0.1

## Mục tiêu
Cài đặt bản APK `JAVIS_DRIVER_PREMIUM_MVP_V0.1.apk` lên điện thoại Android để thực hiện bài kiểm tra thực tế chuyến đi làm sáng 22/09/2026.

---

## Các bước cài đặt:

### 1. Chép file APK vào điện thoại
- File APK: [`release/JAVIS_DRIVER_PREMIUM_MVP_V0.1/JAVIS_DRIVER_PREMIUM_MVP_V0.1.apk`](file:///g:/05.%20GEM%20GEMINI%202026/19.%20Javis%20Driver%20Premium/release/JAVIS_DRIVER_PREMIUM_MVP_V0.1/JAVIS_DRIVER_PREMIUM_MVP_V0.1.apk)
- Bạn có thể chuyển qua cáp USB, Zalo cá nhân, Google Drive hoặc Telegram.

### 2. Cài đặt APK
- Nhấn mở file APK trên điện thoại.
- Nếu Android cảnh báo *"Cài đặt ứng dụng từ nguồn không xác định"*, chọn **Cho phép** (Allow from this source).
- Nhấn **Cài đặt (Install)**.

### 3. Cấp quyền định vị & Thông báo
- Mở ứng dụng **JAVIS Driver**.
- Khi ứng dụng yêu cầu quyền vị trí, chọn **"Trong khi dùng ứng dụng"** (While using the app) hoặc **"Chính xác" (Precise)**.
- Cho phép quyền **Thông báo (Notifications)** để ứng dụng duy trì theo dõi khi màn hình tắt / chuyển ứng dụng khác.

### 4. Bắt đầu lái xe
- Nhấn nút xanh **[ START DRIVE ]**.
- Đặt điện thoại lên giá đỡ trên xe ở vị trí dễ nhìn.
- Ứng dụng sẽ hiển thị tốc độ số lớn, giới hạn tốc độ và phát âm thanh cảnh báo bằng giọng nói tiếng Việt tự động.

### 5. Kết thúc & Lưu bằng chứng
- Khi đến nơi, nhấn **[ KẾT THÚC CHUYẾN ĐI (END DRIVE) ]**.
- Bảng tổng kết chuyến đi sẽ hiện ra và lưu toàn bộ log bằng chứng vào bộ nhớ máy.
